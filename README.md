# 🃏 Projeto Clone Yu-Gi-Oh

Este projeto é um **clone visual inspirado no universo de Yu-Gi-Oh!**, criado com o objetivo de praticar habilidades de desenvolvimento web, especialmente com foco em **HTML, CSS e JavaScript**. A interface simula o visual clássico das cartas e elementos do jogo, com um design estilizado para fãs da franquia.

## 🚀 Funcionalidades

- Visual interativo inspirado nas cartas de Yu-Gi-Oh
- Estilização temática com cores, bordas e fontes personalizadas
- Estrutura responsiva e compatível com diferentes dispositivos
- Elementos visuais como campos de batalha, áreas de carta, etc.

---

## 🧰 Tecnologias Utilizadas

- **HTML5** – Estrutura do projeto
- **CSS3** – Estilização visual
- **JavaScript** – Lógica e interatividade (caso aplicável)
- **GitHub Pages** – Para publicação online (se estiver ativado)

---

## 🎯 Objetivos

- Praticar criação de layout com fidelidade temática
- Aplicar conceitos de responsividade e boas práticas de front-end
- Criar um projeto divertido e visualmente atrativo
